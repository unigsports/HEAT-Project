# Ceramic Intelligence Loop — HEAT / ATF Window 3a project workspace

Working files for the UGC HEAT Academic Transformation Fund proposal on green-stage and fired-stage ceramic tile defect detection, and for the DBL Group pilot pitch.

| Path | What it is |
|------|------------|
| `docs/Proposal_Audit_and_Feasibility.md` | Line-by-line number audit of Section A and Annex 1, technical feasibility of green-body defect detection, and a startup assessment for Bangladesh. |
| `deck/DBL_Group_Proposal.pptx` | 15-slide pilot partnership proposal for DBL Ceramics Ltd. Rebuild with `node deck/build_deck.js` (needs `pptxgenjs` on `NODE_PATH` and `PPTX_SKILL_DIR` pointing at the pptx skill scripts). |
| `web/index.html` | Standalone webpage: interactive Three.js model of the inspection line, the four product tiers, defect coverage map, savings calculator and pilot plan. Open directly in a browser (loads Three.js from jsDelivr). |
| `web/page.html` | Same page as published through the claude.ai artifact (no HTML skeleton). |

All savings figures are illustrative and should be replaced with audited numbers from the pilot plant.
