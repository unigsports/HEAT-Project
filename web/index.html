What we can build

Four products, one platform

Each tier works on its own and plugs into the next. A factory can start with the green node alone and add the rest as the savings land.

TIER 1

Green Node

Press exit and dryer exit
  • Line-scan camera with low-angle grazing light for chips, cracks and lumps
  • 3D laser profiler: thickness map, die-fill variation, ±50 µm
  • Load cell + 3D volume = bulk density of every tile
  • Thermal camera at the dryer exit for internal laminations
  • Pneumatic rejector; green scrap goes straight back to the mill
  • Edge GPU, under 20 ms per tile, encoder-synchronised
Target: 60–70% of structural rejects stopped before firing
Indicative BDT 25–35 lakh per station
TIER 2

Fired Node

Kiln exit, before sorting
  • Multi-camera array with polarised lighting
  • Surface model (YOLOv8/v10 family) trained on your own designs, so marble veins are not called defects
  • Classes: cracks, pinholes, chips, spots, glaze faults, print errors, shade
  • 3D flatness: centre curvature, edge curvature, warpage, wedging, calibre per ISO 10545-2
  • Grade A / B / reject signal to the existing sorter
Target: mAP ≥ 0.90, consistent across three shifts
Indicative BDT 25–40 lakh per station
TIER 3

The Loop

Root-cause engine and machine feedback
  • Reads press pressure, dryer temperatures, glaze density and kiln-zone curves (PLC tags, OPC-UA or logs)
  • Correlates defect bursts with upstream telemetry by time and position
  • Phase 1: recommended set-points shown to the operator with the evidence
  • Phase 2: OPC-UA write-back with an audit log, where the plant and machine vendor agree
Turns detection into prevention
Software subscription per line
TIER 4

Factory OS

Cloud dashboard for the whole plant
  • Live defect rate, grade split and OEE per line, on any phone
  • Shift and daily reports generated automatically, Bangla and English
  • Defect bursts open tasks for the right technician; closure tracked
  • Every tile becomes a labelled record: an R&D database for bodies, glazes, suppliers and kiln curves
  • Data stays on the factory's own servers
Replaces paper logbooks and end-of-shift spreadsheets
Subscription per plant
